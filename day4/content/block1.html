Block 1: Vibe-code IaC and deploy to Azure (70 min)

You will: write Terraform with Copilot from a short spec, run plan and apply, and check what was created with a scorer. The trainer then opens the Azure Portal on screen so everyone sees the real resources. All of it lands in your own resource group (already created for you).

Why spec-driven, not prompt-driven (10 min)

A one-line prompt — "write Terraform for Azure storage" — leaves Copilot to guess the SKU, the region, whether versioning is on, what tags you want, and the API version. You pay for those guesses in production. A short spec with numbered requirements removes the guesswork.

Keep in mind: the spec is the artifact that outlives this chat. Save it. Re-use it. Hand it to the next person on your team.
